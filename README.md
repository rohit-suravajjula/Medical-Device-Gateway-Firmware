# Medical Device Gateway Firmware

## Overview

This repository contains the complete design and development of a Medical Device Gateway Firmware project.

The project is built step by step, starting from requirements and system architecture to firmware implementation and testing.

## Project Structure

- 02_System_Architecture
- 03_Firmware_Boundary
- 04_Firmware_Architecture
- 05_RTOS_Architecture
- 06_Module_Design
- 07_Firmware_Implementation
- 08_Testing
